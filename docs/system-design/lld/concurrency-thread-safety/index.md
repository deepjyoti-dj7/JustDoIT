# Concurrency and Thread Safety

Writing classes that work correctly when accessed by multiple threads simultaneously. This section covers the theory, mechanisms, and patterns you need for LLD interviews and production systems.

| Topic | What you'll learn |
|---|---|
| Concurrency Fundamentals | Threads, JMM, shared state, the three pillars of thread safety |
| Synchronization Mechanisms | synchronized, volatile, atomics, locks, semaphores |
| Deadlocks & Race Conditions | Detection, prevention, and fix strategies |
| Immutability & Thread-Safe Design | Eliminating synchronization through design |
| Concurrent Design Patterns | Producer-consumer, thread pools, futures, active objects |
