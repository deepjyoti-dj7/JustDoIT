# Testing

Writing code that's provably correct, maintainable, and refactorable with confidence. This section covers testing strategies, techniques, and design principles that make code easy to verify.

| Topic | What you'll learn |
|---|---|
| Unit Testing | AAA pattern, naming, edge cases, parameterized tests |
| Integration Testing | Database tests, API tests, WireMock, Testcontainers |
| Test-Driven Development | Red-Green-Refactor, TDD by example, when TDD shines |
| Mocking and Fakes | Stubs vs mocks vs fakes, mocking patterns, anti-patterns |
| Testable Design | DI, SOLID-testability link, separating logic from I/O |
